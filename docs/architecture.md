# 架构

Tvpn 是 Go 单体服务，内嵌 React 构建产物。PostgreSQL 保存身份、策略、代理上下文和审计数据。

管理界面使用 `TVPN_APP_ORIGIN`，代理内容使用 `TVPN_PROXY_BASE_DOMAIN` 下的独立 Origin。生产环境必须将二者部署在同一可注册域名下，并为代理域配置泛域名 DNS 和 TLS。每个上游 Origin 映射到不可预测的代理子域，防止不同目标站点共享浏览器同源权限。

请求路径分为：

1. 文档导航和解析前资源通过 HTTP 代理。
2. 注入运行时捕获可拦截请求并通过 WebSocket 多路复用。
3. 上游原生 WebSocket 使用独立隧道。

用户在管理域创建代理上下文时选择服务端直连或一个获授权的 HTTP/SOCKS5 上游代理，随后会获得两分钟有效、只能使用一次的 bootstrap URL。出口选择固定在上下文内；bootstrap 在 `.proxy` 域设置独立 HttpOnly 会话，再跳转到随机 Origin 路由。管理会话不会暴露给被代理页面。

服务端对每次导航、子资源和重定向重新解析 DNS，先检查所有解析地址，再将实际连接固定到已检查地址。直连、HTTP CONNECT 和 SOCKS5 都使用该固定地址，TLS SNI 与 HTTP Host 仍保留原始域名。这样策略判断和 TCP/TLS 连接使用同一地址集合，避免 DNS 重绑定绕过。

用户可用代理取用户直接授权与当前 LDAP 组授权的并集，服务端直连始终可选。每次上游连接都会重新检查代理是否启用且用户仍获授权；撤权和停用无需等待上下文过期即可生效。
